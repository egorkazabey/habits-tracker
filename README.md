# Привычки — Telegram Mini App

Трекер привычек внутри Telegram. Данные каждого пользователя хранятся
через `Telegram.WebApp.CloudStorage` — облачное хранилище, привязанное
к паре «бот + аккаунт пользователя». Отдельный backend и база данных
не нужны, поэтому размещение приложения ничего не стоит: нужен только
бесплатный статический хостинг для файлов фронтенда.

Вне Telegram (`npm run dev` в обычном браузере) приложение автоматически
переключается на `localStorage`, чтобы можно было разрабатывать и
проверять UI без бота.

## Локальный запуск

```bash
npm install
npm run dev
```

## Деплой (бесплатно)

Подходит любой статический хостинг с HTTPS, например Vercel или
GitHub Pages.

**Vercel:**
1. Залить репозиторий на GitHub.
2. На vercel.com → New Project → выбрать репозиторий (framework определится как Vite автоматически).
3. Deploy — получите постоянный URL вида `https://<project>.vercel.app`.

**GitHub Pages:**
1. В `vite.config.ts` добавить `base: '/<repo-name>/'`.
2. `npm run build`, задеплоить содержимое `dist/` через Pages (например, `gh-pages` пакетом или GitHub Actions).

## Настройка бота (BotFather)

1. В Telegram открыть `@BotFather` → `/newbot`, задать имя и юзернейм — получите токен бота (нужен только для базовой настройки, сервер не потребуется).
2. `/mybots` → выбрать бота → `Bot Settings` → `Menu Button` → `Configure Menu Button` → указать задеплоенный HTTPS URL. Это откроет приложение по кнопке рядом с полем ввода в чате с ботом.
3. Либо `/newapp`, чтобы создать полноценное Mini App с собственной иконкой и именем в списке приложений.

После этого у каждого пользователя, открывшего приложение через бота,
данные о привычках будут сохраняться в его Telegram-аккаунте и
загружаться на любом устройстве, где он открыт в Telegram.

## Ограничения CloudStorage

- До 1024 ключей, до 4096 символов на значение — для личного трекера
  привычек этого хватает на годы истории (данные по месяцам хранятся
  отдельными ключами).
- Данные видны только этому боту и не синхронизируются с другими ботами
  или обычным Telegram Cloud.
